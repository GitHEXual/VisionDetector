# VisionDetector

Веб-клиент для проекта VisionDetector: вход, регистрация и кабинет.

## Стек

- React + TypeScript + Vite
- React Router
- Локальная сессия в браузере (логин / пароль)

## Запуск

```bash
cd web
npm install
npm run dev
```

Откройте [http://localhost:5173/login](http://localhost:5173/login).

## Что внутри

- ASCII-анимированный фон
- Кастомный курсор
- Анимированный логотип-глаз
- Страницы входа и регистрации
